New `@ux-sting/motion` package: a zero-dependency CSS transition catalog (card resize, number pop-in, notification stack, list reorder with View Transitions + FLIP, accordion, tab indicator, toast, skeleton → content) with helpers and React hooks, plus an optional GSAP adapter (`@ux-sting/motion/gsap`: useGSAP hooks, ScrollTrigger reveal/pin/scrub, SplitText headings, Flip layouts, timeline presets). `ux-sting qa` no longer flags breadcrumb navs, headings or inline elements as orphaned or off-center bands.
