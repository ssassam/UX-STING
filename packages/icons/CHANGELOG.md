# @ux-sting/icons

## 0.8.0

### Minor Changes

- 8e8e9d3: Animated icons layer: new `@ux-sting/icons/animated` subpath with the `AnimatedIcon` wrapper, a `withIconMotion` HOC and 12 flagship marks (nudge, draw, launch, ring, beat, twinkle, spin, peek, flash, drop, shift, plus mount-drawn check). Motions run from a zero-dependency stylesheet (`@ux-sting/icons/animated.css`) with hover/mount/loop triggers, token-aware durations and easings (`--ui-duration-*`, `--ui-ease-*`), `currentColor` theming and full `prefers-reduced-motion` support.
