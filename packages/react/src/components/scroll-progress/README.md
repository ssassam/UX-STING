# ScrollProgress

> Motion & effects · `@ux-sting/react/scroll-progress`

Reading-progress bar driven by CSS scroll timelines, with a passive scroll listener as fallback.

## When to use

Use on long articles and documentation pages.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { ScrollProgress } from "@ux-sting/react/scroll-progress";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add scroll-progress
```

## Accessibility

- Decorative and `aria-hidden`; mirrors in RTL.

## API

### ScrollProgress

Reading-progress bar for long articles and docs. It uses CSS scroll-driven animations where the browser supports them, with a passive scroll listener as the fallback. The bar is decorative, so it is hidden from assistive tech.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `fixed` | `boolean` | `true` | Pin to the top of the viewport. Default `true`; set `false` to place it yourself. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
