# Navbar

> Navigation · `@ux-sting/react/navbar`

Site/app header with brand, links, actions and a mobile menu sheet.

## When to use

Use as the primary top navigation on every page, in the same place.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Navbar, NavbarMobileMenu, NavbarBrand } from "@ux-sting/react/navbar";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add navbar
```

## Accessibility

- Current page uses `aria-current="page"`; the mobile menu is a labelled dialog that closes on navigation.

## Responsive behavior

Links collapse into NavbarMobileMenu below `md`.

## API

### Navbar

Top application/site bar. Compose `NavbarBrand`, `NavbarContent` (desktop links), `NavbarActions` and `NavbarMobileMenu` (sheet on small screens). Keep primary nav placement consistent across pages.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `blurred` | `boolean` | `true` | Translucent blurred background (for content scrolling beneath). |
| `maxWidth` | `"md" \| "lg" \| "xl" \| "full"` | `"xl"` | Max width of the inner container. |
| `sticky` | `boolean` | `true` | Stick to the top on scroll. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
