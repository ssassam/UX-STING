# RotatingText

> Motion & effects · `@ux-sting/react/rotating-text`

RotatingText cycles words in place without reflow; Typewriter types, erases and loops phrases with space reserved for the longest.

## When to use

Use in a hero to show several audiences or use cases in one line.

**Consider alternatives:** Avoid for information people need: hidden words are easy to miss.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { RotatingText, Typewriter } from "@ux-sting/react/rotating-text";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add rotating-text
```

## Accessibility

- Screen readers hear the full list once, not every change.
- Reduced motion keeps the first word (RotatingText) or shows the full text (Typewriter); without JavaScript the text is shown.

## API

### RotatingText

Cycles through words in place ("Build apps that are fast / safe / yours"). All words share one grid cell, so the line never reflows. Screen readers hear the full list once instead of every change; reduced motion keeps the first word.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `words` * | `string[]` | — | Words or short phrases to cycle through. |
| `interval` | `number` | `2500` | Time each word stays, in ms. Default 2500. |
| `paused` | `boolean` | `false` | Stops on the current word. |
| `srText` | `string` | — | What screen readers hear instead. Defaults to the words joined by commas. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### Typewriter

Types text character by character. Space for the longest phrase is reserved, so nothing below jumps. Screen readers and reduced motion get the full text immediately; without JavaScript the text is simply shown.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `text` * | `string \| string[]` | — | Text to type. Pass several to type, erase and loop through them. |
| `cursor` | `boolean` | `true` | Show a blinking caret. Default `true`. |
| `hold` | `number` | `1800` | Pause on a finished phrase before erasing, in ms. Default 1800. |
| `speed` | `number` | `45` | Ms per character. Default 45. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
