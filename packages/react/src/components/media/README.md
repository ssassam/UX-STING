# Image

> Media · `@ux-sting/react/media`

Image (reserved ratio, lazy, fallback), ImageGallery, Lightbox, Video (captions) and Audio (transcript).

## When to use

Use for all content media.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Image, ImageGallery, Lightbox } from "@ux-sting/react/media";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add media
```

## Accessibility

- `alt` is required (empty for decorative).
- Video accepts caption tracks; Audio can link a transcript; Lightbox supports arrow keys.

## API

### Image

Responsive image with reserved space, lazy loading, a skeleton while loading and a graceful fallback. Pass `srcSet`/`sizes` for responsive art. For Next.js, use `next/image` inside `AspectRatio` or pass it via props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `alt` * | `string` | — | Required: describe the image, or `""` if purely decorative. |
| `containerClassName` | `string` | — | Wrapper class name. |
| `fallback` | `ReactNode` | — | Rendered if the image fails to load. |
| `fit` | `"cover" \| "contain"` | `"cover"` |  |
| `radius` | `"none" \| "sm" \| "md" \| "lg" \| "xl" \| "full"` | `"md"` |  |
| `ratio` | `number` | — | Aspect ratio reserved before load (prevents layout shift). |

_Also accepts 291 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### ImageGallery

Thumbnail grid that opens a Lightbox. Each thumbnail is a button.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `images` * | `LightboxImage[]` | — |  |
| `className` | `string` | — |  |
| `columns` | `2 \| 3 \| 4` | `3` | Grid columns on ≥ sm screens. |
| `layout` | `"grid" \| "mosaic"` | `"grid"` | `mosaic` shows one large image plus groups of four (four columns from `sm`), so the grid never has gaps; extra images go behind the "+n" tile. With fewer than five images it falls back to `grid`. |
| `max` | `number` | — | Maximum thumbnails shown; the last one shows "+n". |
| `ratio` | `number` | `4 / 3` |  |

### Video

Native video with reserved aspect ratio and caption tracks. Autoplay is only allowed muted and respects reduced motion (use `autoPlay` sparingly).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `ratio` | `number` | `16 / 9` | Aspect ratio reserved for the player. |
| `title` | `string` | — | Accessible title. |
| `tracks` | `MediaTrack[]` | `[]` | Caption/subtitle tracks (WebVTT). Provide captions for spoken content. |

_Also accepts 296 standard HTML/React attributes (className, style, aria-*, event handlers…)._
