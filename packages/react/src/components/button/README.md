# Button

> Buttons · `@unified-ui/react/button`

Primary action element with variants, sizes, icons and loading state. Also IconButton and ButtonGroup.

## When to use

Use for actions (submit, open, save). Keep one `default` (primary) button per view.

**Consider alternatives:** Use Link (or `asChild` with an anchor) for navigation.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Button, IconButton, ButtonGroup } from "@unified-ui/react/button";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add button
```

## Accessibility

- Renders a native `<button type="button">`; `loading` sets `aria-busy` and disables the button.
- IconButton requires `aria-label` and expands its hit area to 44px on touch devices.
- Focus ring uses the `ring` token and is always visible for keyboard users.

### Keyboard

| Keys | Action |
| --- | --- |
| Enter / Space | Activate |

## API

### Button

The primary action element. One `default` (primary) button per view keeps hierarchy clear; use `secondary`/`outline`/`ghost` for supporting actions.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `active` | `boolean` | — | Visually active state, e.g. current item in a toolbar. |
| `asChild` | `boolean` | — | Render the child element (e.g. a link) with button styles. |
| `endIcon` | `ReactNode` | — | Icon after the label (inline-end, RTL-aware). |
| `fullWidth` | `boolean` | — |  |
| `loading` | `boolean` | `false` | Shows a spinner, sets `aria-busy` and prevents interaction. |
| `loadingText` | `ReactNode` | — | Replaces the label while loading (announced to screen readers). |
| `size` | `"sm" \| "md" \| "lg" \| "xl" \| "xs"` | — |  |
| `startIcon` | `ReactNode` | — | Icon before the label (inline-start, RTL-aware). |
| `variant` | `"default" \| "link" \| "destructive" \| "success" \| "warning" \| "secondary" \| "outline" \| "ghost"` | — |  |

_Also accepts 290 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### IconButton

Square/circle button for a single icon. Requires `aria-label`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `aria-label` * | `string` | — | Required accessible name — icon-only buttons must be labelled. |
| `active` | `boolean` | — | Visually active state, e.g. current item in a toolbar. |
| `asChild` | `boolean` | — | Render the child element (e.g. a link) with button styles. |
| `loading` | `boolean` | — | Shows a spinner, sets `aria-busy` and prevents interaction. |
| `shape` | `"square" \| "circle"` | `"square"` | Shape; `circle` for floating actions. |
| `size` | `"sm" \| "md" \| "lg" \| "xl" \| "xs"` | `"md"` |  |
| `variant` | `"default" \| "link" \| "destructive" \| "success" \| "warning" \| "secondary" \| "outline" \| "ghost"` | — |  |

_Also accepts 289 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### ButtonGroup

Groups related buttons. Provide an `aria-label` describing the group.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `attached` | `boolean` | `false` | Visually join buttons (shared borders, no gaps). |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |  |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
