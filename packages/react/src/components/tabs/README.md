# Tabs

> Navigation · `@unified-ui/react/tabs`

Switch between related views (line, pills, enclosed; horizontal or vertical).

## When to use

Use for peer views of the same object.

**Consider alternatives:** Do not use tabs for sequential steps (use Stepper).

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Tabs, TabsList, TabsTrigger } from "@unified-ui/react/tabs";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add tabs
```

## Accessibility

- ARIA tabs with automatic or manual activation.
- Tab `value`s are used to build element ids — use slugs without spaces.

### Keyboard

| Keys | Action |
| --- | --- |
| ← / → | Previous / next tab (mirrored in RTL) |
| Home / End | First / last tab |

## Responsive behavior

Tab lists scroll horizontally on narrow screens.

## API

### Tabs

Switch between related views in the same context. Arrow keys move between tabs (RTL-aware); set `activationMode="manual"` for expensive panels.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `activationMode` | `'automatic' \| 'manual'` | — | Whether a tab is activated automatically or manually. |
| `asChild` | `boolean` | — |  |
| `defaultValue` | `string` | — | The value of the tab to select by default, if uncontrolled |
| `dir` | `RovingFocusGroupProps['dir']` | — | The direction of navigation between toolbar items. |
| `onValueChange` | `(value: string) => void` | — | A function called when a new tab is selected |
| `orientation` | `RovingFocusGroupProps['orientation']` | — | The orientation the tabs are layed out. Mainly so arrow navigation is done accordingly (left & right vs. up & down) |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |  |
| `value` | `string` | — | The value for the selected tab, if controlled |
| `variant` | `TabsVariant` | `"line"` |  |
