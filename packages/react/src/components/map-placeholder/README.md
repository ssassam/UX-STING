# MapPlaceholder

> Patterns · `@ux-sting/react/map-placeholder`

Dependency-free map stand-in with accessible pins, plus MapPanel list/map layout.

## When to use

Use before integrating a map provider, or as a lightweight static map.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { MapPlaceholder, MapPanel } from "@ux-sting/react/map-placeholder";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add map-placeholder
```

## Accessibility

- Pins are labelled buttons; the region has a descriptive label. Always offer a list alternative.

## Responsive behavior

MapPanel stacks the map above the list on mobile.

## API

### MapPlaceholder

Lightweight, dependency-free map stand-in: grid background with positioned, keyboard-accessible pins. Swap for a real map provider later without changing surrounding layout.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — |  |
