# SearchInput

> Forms · `@ux-sting/react/search-input`

Search field with icon, clear button, loading state and optional global shortcut.

## When to use

Use for search boxes in headers, tables and directories.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { SearchInput } from "@ux-sting/react/search-input";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add search-input
```

## Accessibility

- Wrapped in `role="search"`; Escape clears; the shortcut hint is hidden from screen readers.

### Keyboard

| Keys | Action |
| --- | --- |
| Enter | Submit search |
| Escape | Clear |
| Shortcut (e.g. ⌘K) | Focus the field |
