# Toast

> Feedback · `@unified-ui/react/toast`

Sonner-style notifications: `toast.success()`, promise toasts, actions (Undo), queueing.

## When to use

Use for brief confirmations and background results.

**Consider alternatives:** Do not use toasts for errors that need action — show them inline.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Toaster } from "@unified-ui/react/toast";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add toast
```

## Accessibility

- Polite live region; errors are assertive. Toasts never steal focus.
- Pause on hover/focus; default duration 5s; reachable via Alt+T.

### Keyboard

| Keys | Action |
| --- | --- |
| Alt+T | Focus notifications |

## API

### Toaster

Renders toasts. Toasts announce politely (never steal focus), pause while hovered or focused, support actions like "Undo", and can be reached via the hotkey (default Alt+T).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | — |  |
| `duration` | `number` | `5000` | Default duration in ms (3–5 s recommended). |
| `hotkey` | `string` | `"alt+t"` | Shortcut that moves focus to the notifications region. |
| `position` | `ToasterPosition` | `"bottom-end"` |  |
| `toaster` | `ToasterStore` | `defaultToaster` |  |
| `visibleToasts` | `number` | `3` | Maximum toasts visible at once; older ones queue. |
