# Tree

> Data display · `@ux-sting/react/tree`

Hierarchical list with expand/collapse, selection and typeahead.

## When to use

Use for file browsers and nested categories.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Tree } from "@ux-sting/react/tree";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add tree
```

## Accessibility

- ARIA tree pattern with levels, set size and position.

### Keyboard

| Keys | Action |
| --- | --- |
| ↑ / ↓ | Move |
| → / ← | Expand / collapse (mirrored in RTL) |
| Home / End | First / last |
| Enter / Space | Select |
| * | Expand siblings |
