# Stat

> Data display · `@ux-sting/react/stat`

Key figures with trend (Stat, StatCard, StatGroup, Metric).

## When to use

Use for dashboard KPIs.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Stat, Metric, StatCard } from "@ux-sting/react/stat";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add stat
```

## Accessibility

- Rendered as description lists; trends use icon + text, not color alone; tabular figures.

## API

### Stat

Key figure with optional trend. Uses tabular numbers and icon+text for trend (not color alone).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` * | `ReactNode` | — |  |
| `value` * | `ReactNode` | — |  |
| `delta` | `ReactNode` | — | Change indicator, e.g. `"+12%"`. |
| `helpText` | `ReactNode` | — |  |
| `icon` | `ReactNode` | — |  |
| `trend` | `"up" \| "down" \| "neutral"` | `"neutral"` | Direction of change; `positive`/`negative` describe meaning, not direction. |
| `trendMeaning` | `"positive-up" \| "positive-down"` | `"positive-up"` | Whether "up" is good (revenue) or bad (churn). |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
