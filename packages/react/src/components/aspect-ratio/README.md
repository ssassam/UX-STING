# AspectRatio

> Foundations · `@unified-ui/react/aspect-ratio`

Reserves space for media at a fixed ratio to prevent layout shift.

## When to use

Use around images, videos, maps and embeds whose size is known in advance.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { AspectRatio } from "@unified-ui/react/aspect-ratio";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add aspect-ratio
```

## Accessibility

- Purely presentational; the media inside needs its own alt text or title.

## API

### AspectRatio

Reserves space for media to prevent layout shift (CLS).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `ratio` | `number` | `1` | Width / height, e.g. `16 / 9`. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
