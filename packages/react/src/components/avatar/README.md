# Avatar

> Data display · `@ux-sting/react/avatar`

Image with initials fallback, presence status and AvatarGroup overflow.

## When to use

Use for people, businesses and brands.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Avatar, AvatarGroup } from "@ux-sting/react/avatar";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add avatar
```

## Accessibility

- Named via `name`; the `+n` overflow is announced ("3 more").

## API

### Avatar

User or entity image with initials fallback while loading or on error.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `alt` | `string` | — |  |
| `fallback` | `ReactNode` | — |  |
| `name` | `string` | — | Person or entity name: used for alt text and initials fallback. |
| `shape` | `"circle" \| "square"` | — |  |
| `size` | `"sm" \| "md" \| "lg" \| "xl" \| "xs"` | — |  |
| `src` | `string` | — |  |
| `status` | `"online" \| "offline" \| "busy" \| "away"` | — | Presence indicator. |
| `statusLabel` | `string` | — |  |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### AvatarGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `max` | `number` | `4` | Maximum avatars to show before a `+n` summary. |
| `moreLabel` | `(count: number) => string` | `(n) => `${n} more`` | Accessible label for the overflow count, e.g. `(n) => \`${n} more\``. |
| `size` | `AvatarProps["size"]` | `"md"` |  |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
