# Spotlight

> Motion & effects · `@ux-sting/react/spotlight`

Spotlight adds a pointer-following glow to a card; Tilt leans content slightly towards the pointer.

## When to use

Use on a handful of feature or pricing cards and hero media.

**Consider alternatives:** Avoid on dense UI, forms and anything people click repeatedly.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Spotlight, Tilt } from "@ux-sting/react/spotlight";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add spotlight
```

## Accessibility

- Mouse and pen only; touch, coarse pointers, reduced motion and forced colors get the static version.
- Effects never cover content or intercept clicks.

## API

### Spotlight

A soft glow that follows the pointer across a card or section. Mouse and pen only — on touch screens nothing changes — and it never covers content or catches clicks. The glow uses the theme's primary color.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `number` | `320` | Glow radius in px. Default 320. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### Tilt

Tilts its content slightly towards the pointer, for hero media and feature cards. It does nothing for touch, coarse pointers or reduced motion, and it animates transform only.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `max` | `number` | `6` | Maximum rotation in degrees. Keep it subtle. Default 6. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
