# Rating

> Patterns · `@unified-ui/react/rating`

Interactive Rating (radio group) and read-only ReviewStars with fractional fill.

## When to use

Use for reviews and feedback.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Rating, ReviewStars } from "@unified-ui/react/rating";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add rating
```

## Accessibility

- Rating is a native radio group; ReviewStars is announced as "4.5 out of 5 stars".

### Keyboard

| Keys | Action |
| --- | --- |
| ← / → | Change rating |

### ReviewStars

Read-only star rating with fractional fill. Announced as text ("4.5 out of 5 stars"), never by color alone. Server-compatible.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` * | `number` | — | Rating value, supports fractions (4.5). |
| `count` | `number` | — | Number of reviews, shown as "(128)". |
| `max` | `number` | `5` |  |
