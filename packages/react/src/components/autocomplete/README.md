# Autocomplete

> Forms · `@ux-sting/react/autocomplete`

Free-text input with fuzzy suggestions (the value need not be a suggestion).

## When to use

Use for search boxes with suggestions, addresses and tags.

**Consider alternatives:** Use Combobox when the value must be one of the options.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Autocomplete } from "@ux-sting/react/autocomplete";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add autocomplete
```

## Accessibility

- ARIA combobox with `aria-autocomplete="list"` and `aria-activedescendant`.

### Keyboard

| Keys | Action |
| --- | --- |
| ↓ | Open / next suggestion |
| Enter | Accept suggestion |
| Escape | Close |

## API

### Autocomplete

Free-text input with suggestions (the value need not be one of them). Implements the ARIA combobox pattern with `aria-activedescendant`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `suggestions` * | `string[]` | — | Suggestions. Filtered locally unless `onSearchChange` handles it. |
| `defaultValue` | `string` | `""` |  |
| `emptyText` | `ReactNode` | — |  |
| `filterLocally` | `boolean` | `true` | Disable local filtering (async/server suggestions). |
| `invalid` | `boolean` | — | Marks the control invalid (normally derived from `Field`). |
| `limit` | `number` | `8` | Maximum suggestions to render. |
| `loading` | `boolean` | — |  |
| `onSelect` | `(value: string) => void` | — | Called when a suggestion is chosen. |
| `onValueChange` | `(value: string) => void` | — |  |
| `size` | `ControlSize` | — |  |
| `value` | `string` | — |  |
| `variant` | `"default" \| "filled"` | — |  |

_Also accepts 305 standard HTML/React attributes (className, style, aria-*, event handlers…)._
