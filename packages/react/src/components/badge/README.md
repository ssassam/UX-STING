# Badge

> Data display · `@ux-sting/react/badge`

Short status or metadata label; CountBadge for numeric counts.

## When to use

Use for statuses (Paid, Open), categories and counts.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Badge, CountBadge } from "@ux-sting/react/badge";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add badge
```

## Accessibility

- Status is conveyed by text, not only color; CountBadge accepts a descriptive label.

## API

### Badge

Short status or metadata label.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | — |  |
| `dot` | `boolean` | — | Status dot before the label — pair with text, never color alone. |
| `icon` | `ReactNode` | — |  |

| `variant` | `"default" \| "primary" \| "destructive" \| "success" \| "warning" \| "info" \| "secondary" \| "outline"` | — |  |

### CountBadge

Numeric count bubble, e.g. unread notifications. Caps at `max`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `count` * | `number` | — |  |
| `className` | `string` | — |  |
