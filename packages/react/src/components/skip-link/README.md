# SkipLink

> Navigation · `@ux-sting/react/skip-link`

Visually hidden link that appears on focus to skip to main content.

## When to use

Render as the first element of every page layout.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { SkipLink } from "@ux-sting/react/skip-link";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add skip-link
```

## Accessibility

- Targets `#main`; SidebarInset renders `<main id="main" tabindex="-1">`.

## API

### SkipLink

First focusable element on the page: lets keyboard users jump past the navigation to `#main` (or `href`). Visible only when focused.

No additional props.

_Also accepts 286 standard HTML/React attributes (className, style, aria-*, event handlers…)._
