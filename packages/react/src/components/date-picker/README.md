# DatePicker

> Date & time · `@ux-sting/react/date-picker`

Date, date range and date-time pickers in a popover calendar.

## When to use

Use for bookings, filters and scheduling.

**Consider alternatives:** For birth dates, three native inputs (day/month/year) are often faster than a calendar.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { DatePicker, DateRangePicker, DateTimePicker } from "@ux-sting/react/date-picker";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add date-picker
```

## Accessibility

- The trigger is a button announcing the selected date; values submit as ISO strings via `name`.

## Responsive behavior

DateRangePicker shows two months on wide screens and one on phones.
