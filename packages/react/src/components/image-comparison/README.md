# ImageComparison

> Motion & effects · `@ux-sting/react/image-comparison`

Before/after slider with a native range input, localized captions and RTL mirroring.

## When to use

Use for retouching, renovations, product upgrades and design diffs.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { ImageComparison } from "@ux-sting/react/image-comparison";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add image-comparison
```

## Accessibility

- A real `<input type="range">`: arrow keys, Home/End and Page Up/Down, announced as a percentage.
- Give both images meaningful `alt` text; vertical page scroll still works on touch.

### Keyboard

| Keys | Action |
| --- | --- |
| ← / → | Move the divider by 1% |
| Page Up / Page Down | Move by 10% |
| Home / End | Show only one image |

## API

### ImageComparison

Before/after slider. The control is a native range input, so arrow keys, Home/End, Page Up/Down, screen readers and touch work without custom code. Vertical page scrolling still works on touch. Mirrors in RTL.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `after` * | `ReactNode` | — | Shown on the inline-end side. |
| `before` * | `ReactNode` | — | Shown on the inline-start side (usually an `Image`). |
| `afterLabel` | `ReactNode` | — |  |
| `beforeLabel` | `ReactNode` | — | Visible corner captions. Pass `null` to hide them. |
| `defaultValue` | `number` | `50` |  |
| `label` | `string` | — | Accessible name of the slider. Defaults to the localized "Compare images". |
| `onValueChange` | `(value: number) => void` | — |  |
| `value` | `number` | — | Divider position in percent (controlled). |

_Also accepts 278 standard HTML/React attributes (className, style, aria-*, event handlers…)._
