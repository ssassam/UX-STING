# VisuallyHidden

> Theming · `@ux-sting/react/visually-hidden`

Hides content visually while keeping it available to screen readers.

## When to use

Use to add context to icon-only or visual-only UI.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { VisuallyHidden } from "@ux-sting/react/visually-hidden";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add visually-hidden
```

## Accessibility

- Prefer visible text whenever possible.

## API

### VisuallyHidden

Hides content visually while keeping it available to assistive tech.

No additional props.

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
