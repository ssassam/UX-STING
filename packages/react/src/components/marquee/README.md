# Marquee

> Motion & effects · `@ux-sting/react/marquee`

Endless row of logos, testimonials or tags that pauses on hover and focus and has a pause button.

## When to use

Use for social proof (customer logos) and decorative tag clouds.

**Consider alternatives:** Avoid for content people must read or act on; use a Carousel or a list.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Marquee } from "@ux-sting/react/marquee";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add marquee
```

## Accessibility

- Pause button and hover/focus pause satisfy WCAG 2.2.2 (Pause, Stop, Hide).
- The duplicate copy is `aria-hidden` and `inert`, so items are announced and focused once.
- Reduced motion turns it into a scrollable row.

### Keyboard

| Keys | Action |
| --- | --- |
| Tab | Moves through items once; focus pauses the motion |

## API

### Marquee

An endless row of logos, quotes or tags. It pauses on hover and focus and has a pause button, as WCAG 2.2.2 requires for motion lasting over five seconds. With reduced motion it becomes a plain scrollable row. The duplicate copy that makes the loop seamless is hidden from assistive tech and the tab order. Mirrors in RTL.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` * | `string` | — | Accessible name, e.g. "Customer logos". |
| `controls` | `boolean` | `true` | Show the play/pause button (WCAG 2.2.2). Default `true`. |
| `duration` | `number` | `40` | Seconds for one full loop. Default 40. |
| `fade` | `boolean` | `true` | Fade the edges. Default `true`. |
| `pauseOnHover` | `boolean` | `true` | Pause while hovered or while focus is inside. Default `true`. |
| `reverse` | `boolean` | `false` | Scroll towards the inline end instead of the start. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
