# OrderSummary

> Commerce · `@ux-sting/react/order-summary`

Cart and checkout totals: subtotal, discounts, shipping, tax and total, with a slot for promo codes and the checkout button. Adapted from Storefront UI (MIT).

## When to use

Use in carts, checkout sidebars and order confirmations.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { OrderSummary } from "@ux-sting/react/order-summary";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add order-summary
```

## Accessibility

- A labelled region containing a description list (`dt`/`dd`).
- Discounts read as deductions ("−€47.70") in text, not only by color.
- Locale-formatted currency with tabular figures.

## API

### OrderSummary

Cart and checkout totals as a description list: subtotal, discounts, shipping, tax and a prominent total. Amounts are locale-formatted with tabular figures; discounts read as deductions in text, not only by color. Adapted from the Storefront UI OrderSummary block (MIT).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `currency` * | `string` | — | ISO 4217 code. |
| `lines` * | `OrderSummaryLine[]` | — |  |
| `children` | `ReactNode` | — | Promo-code field, checkout button, trust badges… rendered below the total. |
| `headingLevel` | `2 \| 3 \| 4` | `2` |  |
| `locale` | `string` | — |  |
| `note` | `ReactNode` | — | Text under the total, e.g. "Taxes included". |
| `title` | `ReactNode` | — | Heading text (defaults to "Order summary"); `null` hides the heading. |
| `total` | `number` | — | Grand total. Computed from `lines` when omitted. |
| `totalLabel` | `ReactNode` | — |  |
