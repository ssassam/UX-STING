# Switch

> Forms · `@unified-ui/react/switch`

On/off control that takes effect immediately.

## When to use

Use for settings and preferences.

**Consider alternatives:** Use Checkbox when the change only applies on submit.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Switch } from "@unified-ui/react/switch";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add switch
```

## Accessibility

- Exposes `role="switch"` with `aria-checked`.
