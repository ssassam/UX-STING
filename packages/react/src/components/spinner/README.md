# Spinner

> Feedback · `@unified-ui/react/spinner`

Indeterminate activity indicator.

## When to use

Use for short waits inside buttons or small areas.

**Consider alternatives:** Use Skeleton for content-shaped loading longer than ~1s.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Spinner } from "@unified-ui/react/spinner";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add spinner
```

## Accessibility

- `role="status"` with a label; pass `label={null}` when a parent already announces loading.

## API

### Spinner

Indeterminate activity indicator. Server-safe; pass a localized `label`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string \| null` | `"Loading"` | Accessible label. Pass `null` when a parent already announces loading. |
| `size` | `"sm" \| "md" \| "lg" \| "xl" \| "xs"` | — |  |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
