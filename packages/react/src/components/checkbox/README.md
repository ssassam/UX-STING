# Checkbox

> Forms · `@unified-ui/react/checkbox`

Binary or indeterminate choice, plus CheckboxGroup for multiple values.

## When to use

Use for independent options and consent inside forms.

**Consider alternatives:** Use Switch for settings that apply immediately.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Checkbox, CheckboxGroup } from "@unified-ui/react/checkbox";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add checkbox
```

## Accessibility

- Supports `indeterminate` (announced as mixed).
- CheckboxGroup renders a fieldset with legend.
