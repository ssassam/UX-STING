# Field

> Forms · `@unified-ui/react/field`

Connects label, control, helper text and error: ids, aria-describedby, aria-invalid, required and disabled.

## When to use

Wrap every form control in a Field so labelling and errors are always correct.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Field, FieldLabel, FieldDescription } from "@unified-ui/react/field";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add field
```

## Accessibility

- Labels are always visible — placeholders are not labels.
- Required fields show an indicator and set `required` on the control.

## API

### Field

Connects a label, control, helper text and error message: ids, `aria-describedby`, `aria-invalid`, `required` and `disabled` are wired automatically. Errors come from `error` or the parent `Form` by `name`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `description` | `ReactNode` | — | Convenience: renders a FieldDescription (helper text). |
| `disabled` | `boolean` | — |  |
| `error` | `ReactNode` | — |  |
| `id` | `string` | — |  |
| `invalid` | `boolean` | — |  |
| `label` | `ReactNode` | — | Convenience: renders a FieldLabel. |
| `name` | `string` | — |  |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` | Label placement. `horizontal` puts label and control side by side on ≥sm. |
| `readOnly` | `boolean` | — |  |
| `required` | `boolean` | — |  |

_Also accepts 279 standard HTML/React attributes (className, style, aria-*, event handlers…)._

| Prop | Type | Default | Description |

### FieldDescription

No additional props.

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### FieldError

Error message placed below the control and referenced by it. Renders the field's error automatically; pass children to override.

No additional props.

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### Fieldset
