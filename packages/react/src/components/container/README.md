# Container

> Foundations · `@ux-sting/react/container`

Centers content with a consistent max width and responsive gutters.

## When to use

Use once per page section to align content to the layout grid.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Container } from "@ux-sting/react/container";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add container
```

## Accessibility

- Use `as="main"` or `as="section"` to create landmarks where appropriate.

## Responsive behavior

Gutters grow from 16px (mobile) to 32px (desktop); sizes sm → prose → full.
