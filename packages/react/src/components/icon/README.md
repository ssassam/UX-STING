# Icon

> Theming · `@unified-ui/react/icon`

Dynamic `<Icon name="search" />` and `createIcon` for custom glyphs.

## When to use

Use for data-driven icons; import icons directly for smallest bundles.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Icon } from "@unified-ui/react/icon";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add icon
```

## Accessibility

- Decorative by default; pass `title` or `aria-label` for meaningful icons.

## API

### Icon

Renders an icon by name: `<Icon name="search" />`. Convenient for data-driven UIs, but it references every icon — prefer direct imports (`import { SearchIcon } from "@unified-ui/icons"`) for the smallest bundles.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` * | `IconName` | — |  |
| `size` | `IconSize \| number \| (string & {})` | — | Token size (`xs`–`xl`), a number in px, or any CSS length. Defaults to `1em`. |
| `title` | `string` | — | Accessible title. When omitted the icon is decorative (`aria-hidden`). |

_Also accepts 487 standard HTML/React attributes (className, style, aria-*, event handlers…)._
