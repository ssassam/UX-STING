# ProductDetails

> Commerce · `@ux-sting/react/product-details`

Product page layout: gallery beside a buy box with brand, title, rating, price, options, quantity, add to cart, reassurance and details. Adapted from Storefront UI (MIT).

## When to use

Use for product detail pages; fill the slots with ProductGallery, SwatchGroup, QuantitySelector and Accordion.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { ProductDetails } from "@ux-sting/react/product-details";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add product-details
```

## Accessibility

- Rendered as an `article` with the product name as `h1`.
- The rating can link to reviews and is announced as text ("4.8 out of 5 stars").
- The details slot sits under a visually hidden h2 ("Product details") so Accordion h3 headings keep a valid outline.

## Responsive behavior

Stacked with the gallery first on phones; two columns from `md`, with a sticky buy box.

### ProductDetails

Product page layout: gallery beside a buy box (brand, title, rating, price, options, quantity and add to cart), stacked on phones with the gallery first. The buy box stays in view while long galleries scroll on desktop. Adapted from the Storefront UI product details block (MIT).
