# PasswordInput

> Forms · `@ux-sting/react/password-input`

Password field with an accessible show/hide toggle.

## When to use

Use for sign-in and account creation.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { PasswordInput } from "@ux-sting/react/password-input";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add password-input
```

## Accessibility

- Never blocks paste or password managers (WCAG 2.2 accessible authentication).
- The toggle announces its state with `aria-pressed`.
