# ColorModeToggle

> Theming · `@ux-sting/react/color-mode-toggle`

Button switching between light and dark mode via UIProvider.

## When to use

Use in headers and settings.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { ColorModeToggle } from "@ux-sting/react/color-mode-toggle";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add color-mode-toggle
```

## Accessibility

- Label describes the action ("Switch to dark mode").

## API

### ColorModeToggle

Switches between light and dark mode via the nearest `UIProvider`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `labels` | `{ toDark: string; toLight: string }` | `{ toDark: "Switch to dark mode", toLight: "Switch to light mode" }` | Accessible labels (localize). |

_Also accepts 288 standard HTML/React attributes (className, style, aria-*, event handlers…)._
