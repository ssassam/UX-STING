# OTPInput

> Forms · `@unified-ui/react/otp-input`

One-time code entry with paste, SMS autofill and grouping.

## When to use

Use for verification codes and PINs.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { OTPInput } from "@unified-ui/react/otp-input";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add otp-input
```

## Accessibility

- Group is labelled; each box announces its position; `autocomplete="one-time-code"` enables autofill.

### Keyboard

| Keys | Action |
| --- | --- |
| ← / → | Move between digits |
| Backspace | Delete and move back |

## API

### OTPInput

One-time code entry. Supports paste of the full code, SMS autofill (`autocomplete="one-time-code"`), arrow keys and Backspace navigation.
