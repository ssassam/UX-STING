# Calendar

> Date & time · `@unified-ui/react/calendar`

Accessible month grid for single dates and ranges; also MonthPicker and YearPicker.

## When to use

Use inline for availability views or inside date pickers.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Calendar, MonthPicker, YearPicker } from "@unified-ui/react/calendar";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add calendar
```

## Accessibility

- ARIA grid pattern with localized day names, first day of week and `aria-current="date"` for today.

### Keyboard

| Keys | Action |
| --- | --- |
| ← → ↑ ↓ | Move by day/week (mirrored in RTL) |
| Home / End | Start / end of week |
| PageUp / PageDown | Previous / next month (+Shift: year) |
| Enter / Space | Select |
