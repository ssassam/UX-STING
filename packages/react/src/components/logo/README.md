# Logo

> Foundations · `@ux-sting/react/logo`

Brand lockup (symbol + wordmark) with locked spacing, horizontal/stacked/mark/wordmark layouts and brand, mono and reversed tones driven by tokens.

## When to use

Use in navbars, footers, auth screens and emails to show your brand consistently. Create the mark with the `logo-design` skill.

**Consider alternatives:** Do not paste raster logos or hard-coded colors; give the mark `fill="currentColor"` so it follows the theme.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Logo } from "@ux-sting/react/logo";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add logo
```

## Accessibility

- Exposed as one image (`role="img"`) or one link named after the brand; the SVG and wordmark are hidden from assistive tech.
- Use `label` for links ("Acme home").

## API

### Logo

Brand lockup: symbol + wordmark with locked spacing and sizes. Exposed to assistive tech as one image (or link) named after the brand; the SVG itself is hidden. For router links, omit `href` and wrap the Logo in your Link. Pair with the `logo-design` skill to create the mark. Server-compatible.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` * | `string` | — | Brand name: the accessible name, and the wordmark when `wordmark` is not given. |
| `href` | `string` | — | Renders the logo as a home link. |
| `label` | `string` | — | Accessible name override, e.g. "Acme home". Defaults to `name`. |
| `layout` | `"horizontal" \| "stacked" \| "mark" \| "wordmark"` | `"horizontal"` | `horizontal` (default), `stacked`, `mark` (symbol only) or `wordmark` (text only). |
| `mark` | `ReactNode` | — | The symbol as inline SVG using `fill="currentColor"`, so it follows tokens and color modes. |
| `size` | `keyof typeof sizes` | `"md"` |  |
| `tone` | `keyof typeof tones` | `"brand"` |  |
| `wordmark` | `ReactNode` | — | Custom wordmark (e.g. a constructed SVG logotype). Defaults to `name` set in the heading font. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
