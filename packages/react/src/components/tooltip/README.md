# Tooltip

> Overlays · `@unified-ui/react/tooltip`

Short supplementary label on hover and keyboard focus.

## When to use

Use to name icon buttons or show shortcuts.

**Consider alternatives:** Never put essential or interactive content in tooltips — they do not exist on touch.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Tooltip, TooltipProvider, TooltipRoot } from "@unified-ui/react/tooltip";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add tooltip
```

## Accessibility

- Appears on focus as well as hover; linked with `aria-describedby`.
