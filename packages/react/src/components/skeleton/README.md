# Skeleton

> Feedback · `@unified-ui/react/skeleton`

Placeholder shapes that reserve layout while content loads.

## When to use

Use for lists, cards and tables while data loads.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Skeleton, SkeletonText } from "@unified-ui/react/skeleton";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add skeleton
```

## Accessibility

- Hidden from assistive tech; set `aria-busy` on the container. Shimmer stops with reduced motion.

## API

### Skeleton

Placeholder that reserves layout while content loads (prevents layout shift). Hidden from assistive tech — announce loading on the container with `aria-busy` instead.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `shape` | `"rect" \| "text" \| "circle"` | `"rect"` | Shape preset. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### SkeletonText

Multi-line text placeholder with a shorter last line.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | — |  |
| `lines` | `number` | `3` |  |
