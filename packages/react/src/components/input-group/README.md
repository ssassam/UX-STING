# InputGroup

> Forms · `@ux-sting/react/input-group`

Wraps an input with leading/trailing addons (icons, units, buttons).

## When to use

Use for currency prefixes, unit suffixes and inline actions.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { InputGroup, InputGroupAddon, InputGroupAction } from "@ux-sting/react/input-group";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add input-group
```

## Accessibility

- Addons are visual; include units in the label or description for screen readers.

## API

### InputGroup

Wraps an input with leading/trailing addons (icons, units, buttons). The group draws the border; the inner input is borderless.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |  |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### InputGroupAddon

Non-interactive addon (icon, unit, prefix text).

No additional props.

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### InputGroupAction

Interactive addon container (buttons inside the field).

No additional props.

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
