# Footer

> Patterns · `@ux-sting/react/footer`

Site footer: optional CTA callout, brand column, multi-column link navigation and a bottom bar with copyright and legal links. Inverse (dark) or surface tone, retintable through --footer-* variables.

## When to use

Use once per site layout as the contentinfo landmark; group links into 3-6 titled columns.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Footer, FooterCallout, FooterMain } from "@ux-sting/react/footer";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add footer
```

## Accessibility

- Renders a <footer> (contentinfo) landmark with a labelled <nav> of headed link lists.
- External links open in a new tab and announce it to screen readers.

## API

### Footer

Site footer (`contentinfo` landmark). Compose `FooterCallout` (optional CTA band), `FooterMain` with `FooterBrand` + `FooterNav` of `FooterColumn`s, then `FooterBottom` with `FooterCopyright` and `FooterLegal`. Links use `FooterLink` (`asChild` for router links).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `maxWidth` | `"md" \| "lg" \| "xl" \| "full"` | `"xl"` | Max width of the inner container. |
| `tone` | `"default" \| "inverse"` | `"inverse"` | `inverse` = dark band in every color mode; `default` = theme surface. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### FooterMain

No additional props.

Logo, tagline, contact and newsletter.

No additional props.

### FooterTagline

No additional props.

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### FooterNav

`<nav>` grid of `FooterColumn`s. Give it an `aria-label`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `columns` | `2 \| 3 \| 4 \| 5 \| 6` | `4` | Columns from `lg` up (2 on phones, 3 on tablets). |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### FooterColumn

Titled list of `FooterLink`s.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` * | `ReactNode` | — |  |
| `headingLevel` | `2 \| 3 \| 4` | `2` | Heading level of the column title (default 2). |

_Also accepts 279 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### FooterLink

A footer link inside `FooterColumn` (renders its own `<li>`).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | — |  |
| `badge` | `ReactNode` | — | Small badge after the label, e.g. "Nouveau". |
| `external` | `boolean` | — | Opens in a new tab with an external-link hint for screen readers. |
| `externalLabel` | `string` | `"(opens in a new tab)"` | Screen-reader hint appended to external links. |
| `icon` | `ReactNode` | — | Leading icon (decorative). |

_Also accepts 288 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### FooterBottom

Bottom bar: copyright on the start side, legal links / switches on the end side.

No additional props.

### FooterLegal

Inline list of legal links, separated by a small dot. Children: `<a>`s or router links.
