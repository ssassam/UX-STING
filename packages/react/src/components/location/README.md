# Location

> Patterns · `@ux-sting/react/location`

Address line with distance and LocationCard with directions.

## When to use

Use on listing cards and business pages.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Location, LocationCard } from "@ux-sting/react/location";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add location
```

## Accessibility

- Rendered as `<address>`; directions link opens a maps app.

## API

### Location

Address line with pin icon and distance. Renders an `<address>`.
