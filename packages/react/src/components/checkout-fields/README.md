# Checkout fields

> Commerce · `@ux-sting/react/checkout-fields`

AddressFields and PaymentFields for checkout: visible labels, section-scoped autofill tokens, mobile keyboards, card and expiry formatting and validation through Form.

## When to use

Use inside a Form for shipping/billing addresses and card payment UI.

**Consider alternatives:** For live payments, put your payment provider's hosted fields in this layout so card data never reaches your server.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { AddressFields, PaymentFields } from "@ux-sting/react/checkout-fields";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add checkout-fields
```

## Accessibility

- Each group is a fieldset with a legend; every field has a visible label and helper text where the format matters.
- `autoComplete` uses `shipping …` / `billing …` and `cc-*` tokens, so browsers fill the form in one tap.
- Required and format errors appear inline and in FormErrorSummary.

## API

### AddressFields

Address block for checkout: visible labels, the right `autoComplete` tokens per section (so browsers and password managers fill it in one tap), mobile keyboards per field and required validation through `Form`. Adapted from the Storefront UI checkout address block (MIT).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `legend` * | `ReactNode` | — | Group legend, e.g. "Shipping address". |
| `className` | `string` | — |  |
| `countries` | `Array<{ value: string; label: string }>` | — | Country options; when omitted the country is a text field. |
| `defaultCountry` | `string` | — |  |
| `disabled` | `boolean` | — |  |
| `hidePhone` | `boolean` | — | Hide the phone field. |
| `hideRegion` | `boolean` | — | Hide the region field (countries without states). |
| `labels` | `Partial<AddressFieldsLabels>` | — |  |
| `section` | `"shipping" \| "billing"` | `"shipping"` | Autofill section and field-name prefix. Field names are `<section>.<field>` (`shipping.line1`), so a shipping and a billing group can share one Form. |

### PaymentFields

Card payment fields with `cc-*` autofill, numeric keyboards, as-you-type formatting and format validation. For real payments, render your payment provider's hosted fields inside the same layout instead, so card data never touches your servers (PCI DSS).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `legend` * | `ReactNode` | — |  |
| `accepted` | `ReactNode` | — | Accepted-card logos or a wallet button row, shown under the legend. |
| `className` | `string` | — |  |
| `disabled` | `boolean` | — |  |
| `labels` | `Partial<PaymentFieldsLabels>` | — |  |
| `name` | `string` | `"payment"` | Field-name prefix. Default `"payment"` → `payment.cardNumber`. |
