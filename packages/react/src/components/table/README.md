# Table

> Data display · `@unified-ui/react/table`

Semantic table primitives with sortable headers, density-aware cells and stacked mobile layout.

## When to use

Use for static or server-rendered tabular data.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Table, TableHeader, TableBody } from "@unified-ui/react/table";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add table
```

## Accessibility

- Sortable headers expose `aria-sort`; scrollable tables are focusable, named regions.

## Responsive behavior

`responsive="stack"` turns rows into labelled cards below `md`.

## API

Semantic data table. Density-aware paddings; server component.
