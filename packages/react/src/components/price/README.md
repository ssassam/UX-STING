# Price

> Patterns · `@unified-ui/react/price`

Locale-aware Price (discounts, periods), PriceRange, PriceLevel ($$) and Currency.

## When to use

Use anywhere money is shown.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Price, Currency, PriceRange } from "@unified-ui/react/price";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add price
```

## Accessibility

- Previous prices have hidden labels; PriceLevel has a text alternative; tabular figures.

## API

### Price

Locale-aware price with optional discount and period. Tabular figures.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `amount` * | `number` | — |  |
| `currency` * | `string` | — | ISO 4217 code, e.g. "USD", "EUR", "MAD". |
| `compareAt` | `number` | — | Previous price; rendered struck through with an accessible label. |
| `compareAtLabel` | `string` | `"Original price"` | Label for the previous price (localize). |
| `fractionDigits` | `number` | — |  |
| `locale` | `string` | — |  |
| `period` | `ReactNode` | — | Suffix such as "/ night" or "per month". |
| `size` | `"sm" \| "md" \| "lg" \| "xl"` | `"md"` |  |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

Relative price indicator ($ – $$$$) for places and restaurants.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `level` * | `number` | — | 1–max, e.g. 2 renders "$$" of "$$$$". |
