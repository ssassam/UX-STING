# Resizable

> Foundations · `@unified-ui/react/resizable`

Split views with draggable, keyboard-accessible handles.

## When to use

Use for editors, master–detail views and IDE-like layouts on larger screens.

**Consider alternatives:** On mobile, stack panels instead of offering resize handles.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { ResizablePanelGroup, ResizablePanel, ResizableHandle } from "@unified-ui/react/resizable";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add resizable
```

## Accessibility

- Handles are `role="separator"` with `aria-valuenow`, focusable and operable by keyboard (dragging is never required).

### Keyboard

| Keys | Action |
| --- | --- |
| ← / → | Resize horizontal panels (mirrored in RTL) |
| ↑ / ↓ | Resize vertical panels |
| Home / End | Minimize / maximize the leading panel |
