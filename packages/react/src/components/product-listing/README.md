# ProductListing

> Commerce · `@ux-sting/react/product-listing`

Category page layout: heading with live result count, filter sidebar (sheet on mobile), applied-filter chips, sort control, product grid and pagination. Built on FilterPanel; adapted from Storefront UI (MIT).

## When to use

Use for category, search-result and collection pages.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { ProductListing } from "@ux-sting/react/product-listing";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add product-listing
```

## Accessibility

- The title is the page `h1`; the result count updates in a polite live region.
- Give product cards `headingLevel={2}` so headings go h1 → h2 without gaps.
- Filters are a labelled `aside` on desktop and a dialog on mobile; applied filters are removable chips.

## Responsive behavior

Sidebar from `lg`; below that a sticky Filters button opens a bottom sheet.

## API

### ProductListing

Category page layout: heading and live result count, a filter sidebar (a sheet on mobile, from the same filters), applied-filter chips, a sort control, the product grid and pagination. Composes FilterPanel. Layout adapted from the Storefront UI category page block (MIT).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` * | `ReactNode` | — | The product grid. |
