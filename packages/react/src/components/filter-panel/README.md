# FilterPanel

> Patterns · `@unified-ui/react/filter-panel`

Sidebar filters on desktop and a sheet on mobile from the same children; FilterSection and FilterChips.

## When to use

Use for search and listing pages.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { FilterPanel, FilterSection, FilterChips } from "@unified-ui/react/filter-panel";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add filter-panel
```

## Accessibility

- Applied filters are removable tags in a labelled group.

## Responsive behavior

Below `lg` filters open in a bottom sheet with an active-count badge.

## API

### FilterPanel

Filters as a sidebar on desktop and a bottom/side sheet on mobile, from the same children. Pair with `FilterChips` to show applied filters.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` * | `ReactNode` | — |  |
| `activeCount` | `number` | `0` | Number of active filters (shown on the mobile trigger). |
| `applyLabel` | `ReactNode` | `"Show results"` | Mobile "Show results" button label and handler. |
| `className` | `string` | — |  |
| `clearLabel` | `string` | `"Clear all"` |  |
| `onApply` | `() => void` | — |  |
| `onClear` | `() => void` | — |  |
| `title` | `ReactNode` | `"Filters"` |  |

### FilterSection
