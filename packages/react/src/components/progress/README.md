# Progress

> Feedback · `@unified-ui/react/progress`

Linear and circular progress, determinate or indeterminate.

## When to use

Use for uploads and multi-step processes with known progress.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Progress, CircularProgress } from "@unified-ui/react/progress";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add progress
```

## Accessibility

- `role="progressbar"` with value text; label via `label` or `aria-label`.

## API

### Progress

Linear progress. Server-safe; uses native `progressbar` semantics.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `formatValue` | `(value: number, max: number) => string` | — |  |
| `label` | `ReactNode` | — | Visible label rendered above the bar (also used as accessible name). |
| `max` | `number` | `100` |  |
| `showValue` | `boolean` | — | Show the formatted value next to the label. |
| `size` | `"sm" \| "md" \| "lg" \| "xs"` | — |  |
| `value` | `number \| null` | `null` | Current value; omit or pass `null` for an indeterminate bar. |
| `variant` | `keyof typeof indicatorColor` | `"default"` |  |
