# Stack

> Foundations · `@ux-sting/react/stack`

Flex layout with token-based, responsive gap and direction. Also exports HStack, VStack, Flex and Spacer.

## When to use

Use for one-dimensional layouts: form fields, button rows, card content.

**Consider alternatives:** Use Grid for two-dimensional layouts.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Stack, Spacer, HStack } from "@ux-sting/react/stack";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add stack
```

## Accessibility

- Visual order equals DOM order; avoid `row-reverse` when it would contradict reading order.

## Responsive behavior

`gap` and `direction` accept responsive objects (`{ base: "column", md: "row" }`) compiled to CSS variables — no client JS.

## API

### Stack

Flex layout with token-based, responsive `gap` and `direction`. Responsive values compile to CSS variables, so Stack is a server component.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `align` | `"start" \| "center" \| "end" \| "stretch" \| "baseline"` | — |  |
| `as` | `ElementType` | — |  |
| `asChild` | `boolean` | — | Render the child element instead, merging props (see `Slot`). |
| `direction` | `Responsive<"row" \| "column" \| "row-reverse" \| "column-reverse">` | — | Main axis direction (responsive). Defaults to `column`. |
| `gap` | `Responsive<SpaceToken>` | `"4"` | Gap between children using the spacing scale (responsive). |
| `justify` | `"start" \| "center" \| "end" \| "between" \| "around" \| "evenly"` | — |  |
| `wrap` | `boolean` | — |  |
