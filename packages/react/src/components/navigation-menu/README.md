# NavigationMenu

> Navigation · `@unified-ui/react/navigation-menu`

Website navigation with dropdown panels (mega menus).

## When to use

Use for marketing sites with grouped destinations.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { NavigationMenu, NavigationMenuList, NavigationMenuItem } from "@unified-ui/react/navigation-menu";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add navigation-menu
```

## Accessibility

- Panels open on hover and on Enter/Space; links remain reachable in order.

### Keyboard

| Keys | Action |
| --- | --- |
| Tab | Move between top-level items |
| Enter / Space / ↓ | Open panel |
| Escape | Close |
