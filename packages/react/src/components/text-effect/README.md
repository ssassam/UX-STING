# TextEffect

> Motion & effects · `@ux-sting/react/text-effect`

Staggered word or character entrances (fade, blur, slide, scale) and TextShimmer for in-progress labels. Pure CSS server components.

## When to use

Use for one hero headline or a status label such as “Generating…”.

**Consider alternatives:** Avoid on body copy, on several headings per screen, and for text that must be read right away.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { TextEffect, TextShimmer } from "@ux-sting/react/text-effect";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add text-effect
```

## Accessibility

- Screen readers get the whole sentence once; the animated pieces are `aria-hidden`.
- Nothing moves under reduced motion; the shimmer turns into plain muted text in forced colors.

## API

### TextEffect

Staggered text entrance in pure CSS: a server component with no client JavaScript. Screen readers get the whole sentence once; the animated pieces are hidden from them. Nothing moves under reduced motion. Inside a `Reveal`, the animation waits until the text scrolls into view.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` * | `string` | — | The text to animate. Plain text only, so it can be split safely. |
| `as` | `ElementType` | `"p"` | Element to render. Default `p`. |
| `delay` | `number` | `0` | Delay before the first piece, in ms. |
| `duration` | `number` | `600` | Duration of each piece, in ms. Default 600. |
| `per` | `"word" \| "char"` | `"word"` | Animate per word or per character. Default `word`. |
| `preset` | `TextEffectPreset` | `"fade"` | Entrance style. Default `fade`. |
| `stagger` | `number` | — | Delay between pieces, in ms. Defaults to 60 (word) or 25 (char). |

_Also accepts 279 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### TextShimmer

A light sweep across text — for "Thinking…", "Generating…" and other in-progress labels. Pure CSS; static under reduced motion and in forced colors. Keep it to short status text, never body copy.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `as` | `ElementType` | `"span"` | Element to render. Default `span`. |
| `duration` | `number` | `2` | Seconds per sweep. Default 2. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
