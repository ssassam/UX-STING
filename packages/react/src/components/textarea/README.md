# Textarea

> Forms · `@ux-sting/react/textarea`

Multi-line input with optional auto-resize and live character count.

## When to use

Use for messages, descriptions and reviews.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Textarea } from "@ux-sting/react/textarea";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add textarea
```

## Accessibility

- The character count is announced politely via `aria-live`.

## API

### Textarea

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `autoResize` | `boolean` | — | Grow with content up to `maxRows`. |
| `invalid` | `boolean` | — |  |
| `maxRows` | `number` | `12` |  |
| `showCount` | `boolean` | — | Show a live character count when `maxLength` is set. |

_Also accepts 294 standard HTML/React attributes (className, style, aria-*, event handlers…)._
