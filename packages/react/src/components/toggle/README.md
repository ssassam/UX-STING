# Toggle

> Buttons · `@unified-ui/react/toggle`

Two-state button (`aria-pressed`) and ToggleGroup with roving focus.

## When to use

Use for formatting toolbars, view switches (list/grid) and filters that apply immediately.

**Consider alternatives:** Use Switch for settings and Checkbox inside forms.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Toggle, ToggleGroup, ToggleGroupItem } from "@unified-ui/react/toggle";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add toggle
```

## Accessibility

- Toggle exposes `aria-pressed`; ToggleGroup is a single tab stop with arrow-key navigation.

### Keyboard

| Keys | Action |
| --- | --- |
| Enter / Space | Toggle |
| ← / → | Move between items in a group |
