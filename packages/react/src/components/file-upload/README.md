# FileUpload

> Forms · `@ux-sting/react/file-upload`

Dropzone and managed file list with validation, progress and removal.

## When to use

Use for documents, photos and attachments.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Dropzone, FileUpload } from "@ux-sting/react/file-upload";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add file-upload
```

## Accessibility

- Drag-and-drop is optional: a real button opens the file picker.
- Rejected files are reported via `onFilesRejected` with a reason.
