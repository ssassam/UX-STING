# NativeSelect

> Forms · `@ux-sting/react/native-select`

Styled native <select>: zero JS, OS pickers on mobile.

## When to use

Use in server-rendered forms and mobile-first flows.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { NativeSelect } from "@ux-sting/react/native-select";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add native-select
```

## Accessibility

- Native semantics and platform accessibility for free.

## API

### NativeSelect

Styled native `<select>`: best on mobile (OS pickers), zero JS, works in server components' forms and without hydration.
