# NavigationRail

> Navigation · `@ux-sting/react/navigation-rail`

Compact vertical navigation (icon + label) for tablets.

## When to use

Use between phone bottom navigation and desktop sidebars.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { NavigationRail, NavigationRailItem } from "@ux-sting/react/navigation-rail";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add navigation-rail
```

## Accessibility

- Items always show text labels; current item uses `aria-current`.

## API

### NavigationRail

Compact vertical navigation (icon + label) for tablets and dense apps. Always show labels: icon-only navigation harms discoverability.
