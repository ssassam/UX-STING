# Grid

> Foundations · `@ux-sting/react/grid`

CSS grid with responsive columns, gaps and auto-fill by minimum child width.

## When to use

Use for card grids, dashboards and galleries.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Grid, GridItem } from "@ux-sting/react/grid";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add grid
```

## Accessibility

- Grid only affects layout; keep a meaningful source order for screen readers.

## Responsive behavior

`columns={{ base: 1, md: 2, lg: 3 }}` or `minChildWidth="16rem"` for intrinsic responsiveness.

## API

### Grid

CSS grid with responsive columns and gaps, rendered on the server.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `as` | `ElementType` | — |  |
| `asChild` | `boolean` | — | Render the child element instead, merging props (see `Slot`). |
| `columns` | `Responsive<number>` | `1` | Column count, responsive: `{ base: 1, md: 2, lg: 3 }`. |
| `gap` | `Responsive<SpaceToken>` | `"4"` |  |
| `minChildWidth` | `string` | — | Auto-fill columns with at least this width (e.g. `"16rem"`); overrides `columns`. |

_Also accepts 379 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### GridItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `span` | `number \| "full"` | — | Number of columns to span (`"full"` spans the row). |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
