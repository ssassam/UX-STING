# Input

> Forms · `@unified-ui/react/input`

Single-line text input with sizes, filled variant and invalid state.

## When to use

Use for short free-text values. Set a semantic `type` and `autoComplete`.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Input } from "@unified-ui/react/input";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add input
```

## Accessibility

- Uses 16px text on mobile to avoid iOS zoom.
- Invalid styling is driven by `aria-invalid` so visuals match semantics.

## API

### Input

Single-line text input. Use a semantic `type` (email, tel, url) and `autoComplete` so mobile keyboards and autofill work. Always pair with a visible label (via `Field`) — placeholders are not labels.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `invalid` | `boolean` | — | Marks the control invalid (normally derived from `Field`). |
| `size` | `ControlSize` | — |  |
| `variant` | `"default" \| "filled"` | — |  |

_Also accepts 309 standard HTML/React attributes (className, style, aria-*, event handlers…)._
