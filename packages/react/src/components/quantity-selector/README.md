# QuantitySelector

> Commerce · `@ux-sting/react/quantity-selector`

Cart quantity control (− / input / +) that clamps to min, max or stock and shows "N in stock". Adapted from Storefront UI (MIT).

## When to use

Use on product pages, cart lines and ticket pickers for small whole-number quantities.

**Consider alternatives:** Use NumberInput for free numeric entry (prices, measurements, decimals).

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { QuantitySelector } from "@ux-sting/react/quantity-selector";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add quantity-selector
```

## Accessibility

- The input is a native `type="number"` spinbutton named "Quantity" (or by its Field label).
- The − and + buttons are real tab stops with `aria-controls`, disabled at the limits.
- Stock text is linked with `aria-describedby`.

### Keyboard

| Keys | Action |
| --- | --- |
| ↑ / ↓ | Increase / decrease |
| Home / End | Minimum / maximum |
| Enter | Commit typed value |

## Responsive behavior

Buttons expand to 44px touch targets on coarse pointers; `fullWidth` for mobile buy bars.
