# Separator

> Foundations · `@unified-ui/react/separator`

Horizontal or vertical divider, optionally with a centered label.

## When to use

Use to separate groups of content or menu sections.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Separator } from "@unified-ui/react/separator";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add separator
```

## Accessibility

- Decorative by default (`role="none"`). Set `decorative={false}` when the separation is meaningful.

## API

### Separator

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `decorative` | `boolean` | `true` | Purely visual separators are hidden from assistive technology (default). |
| `label` | `ReactNode` | — | Optional centered label, e.g. "or". |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |  |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
