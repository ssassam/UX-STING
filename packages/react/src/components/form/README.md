# Form

> Forms · `@ux-sting/react/form`

Accessible form with zero-config constraint validation, validate-on-blur, async submit and an error summary.

## When to use

Use for every data-entry form. Works standalone or with external errors (server, React Hook Form).

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Form, FormErrorSummary } from "@ux-sting/react/form";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add form
```

## Accessibility

- Validates on submit and re-validates on blur — never on every keystroke.
- After a failed submit, focus moves to FormErrorSummary (linking to each invalid field) or the first invalid field.
- Inline errors stay next to their fields and are referenced via `aria-describedby`.

## API

### Form

Accessible form with zero-config validation: fields are validated on submit and re-validated on blur (not on every keystroke). After a failed submit, focus moves to the `FormErrorSummary` (or the first invalid field).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `errors` | `FormErrors` | — | External errors (e.g. from a server response or React Hook Form), keyed by field name. |
| `onSubmit` | `(values: FormValues, event: FormEvent<HTMLFormElement>) => void \| Promise<void>` | — | Called with parsed values only when the form is valid. |
| `validate` | `(values: FormValues) => FormErrors \| undefined \| Promise<FormErrors \| undefined>` | — | Custom validation, run on submit after native constraint validation. |
| `validationBehavior` | `"aria" \| "native" \| "none"` | `"aria"` | `aria` (default): uses the browser's constraint validation (`required`, `type="email"`, `min`…) but renders accessible inline errors instead of native bubbles. `native` keeps browser bubbles. `none` skips validation. |

_Also accepts 287 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### FormErrorSummary

Focusable summary of all errors after a failed submit, linking to each invalid field. Inline field errors remain. Place it at the top of the form.

No additional props.

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
