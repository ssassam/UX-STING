# NumberInput

> Forms · `@ux-sting/react/number-input`

Locale-aware numeric input with steppers, clamping and keyboard support.

## When to use

Use for quantities, guests, prices and other bounded numbers.

**Consider alternatives:** Use Slider for approximate values and Input for identifiers such as phone numbers.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { NumberInput } from "@ux-sting/react/number-input";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add number-input
```

## Accessibility

- Exposes `role="spinbutton"` with `aria-valuenow/min/max/text`; parses localized input ("1 234,5", Arabic digits).

### Keyboard

| Keys | Action |
| --- | --- |
| ↑ / ↓ | Increment / decrement |
| PageUp / PageDown | Step ×10 |
| Home / End | Min / max |

## API

### NumberInput
