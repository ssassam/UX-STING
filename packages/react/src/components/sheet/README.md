# Sheet

> Overlays · `@ux-sting/react/sheet`

Edge-anchored panel (start, end, top, bottom) with logical sides for RTL.

## When to use

Use Sheet for mobile-oriented contextual panels: filters, navigation, details.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Sheet, SheetTrigger, SheetClose } from "@ux-sting/react/sheet";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add sheet
```

## Accessibility

- Same focus management as Dialog.

## Responsive behavior

Widths clamp to the viewport; bottom sheets respect safe areas.

## API

### Sheet

Use Sheet for contextual panels that slide from an edge — filters, navigation on mobile, detail views — while keeping the page context. Sides are logical (`start`/`end`) so they flip in RTL.
