# Backgrounds

> Motion & effects · `@ux-sting/react/background`

Decorative CSS-only layers: MeshGradient, DotPattern, GridPattern, Grain and ProgressiveBlur, colored by theme tokens.

## When to use

Use behind heroes, empty states and section dividers to add depth without images.

**Consider alternatives:** Avoid stacking several layers or putting them behind long body text.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { MeshGradient, DotPattern, GridPattern } from "@ux-sting/react/background";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add background
```

## Accessibility

- All layers are `aria-hidden` and ignore the pointer; they are removed in forced colors.
- Keep text contrast against the strongest point of the gradient; MeshGradient drift stops under reduced motion.

## Responsive behavior

Server components with no JavaScript, canvas or image downloads.

## API

### MeshGradient

Soft multi-color glow built from layered radial gradients.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `animate` | `boolean` | `false` | Slow drift (about 20s per cycle). Stops under reduced motion. |
| `intensity` | `number` | `35` | Strength of the colors, 0–100. Default 35. |
| `tones` | `ToneToken[]` | `["primary", "info", "accent"]` | Two to four theme colors. Default `["primary", "info", "accent"]`. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### DotPattern

Dot grid in the border color — a quiet texture behind heroes and empty states.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `fade` | `boolean` | `true` | Fade the pattern out towards the edges. Default `true`. |
| `size` | `number` | `24` | Cell size in px. Default 24. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### GridPattern

Hairline grid, for technical and editorial layouts.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `fade` | `boolean` | `true` | Fade the pattern out towards the edges. Default `true`. |
| `size` | `number` | `48` | Cell size in px. Default 24. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### Grain

Film-grain noise from an inline SVG filter. Breaks up flat fills and gradient banding.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `opacity` | `number` | `0.08` | 0–1. Default 0.08 — grain should be felt, not seen. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._

### ProgressiveBlur

Blur that increases towards one edge, so text over a scrolling list or an image stays readable. Place it over the area to soften. Under `prefers-reduced-transparency` it becomes a plain fade.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `blur` | `number` | `12` | Maximum blur in px. Default 12. |
| `side` | `"top" \| "bottom"` | `"bottom"` | Edge the blur grows towards. Default `bottom`. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
