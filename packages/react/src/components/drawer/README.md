# Drawer

> Overlays · `@ux-sting/react/drawer`

Bottom drawer with drag-to-dismiss handle for mobile-first flows.

## When to use

Use Drawer when content should remain spatially connected to the current page on phones.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Drawer, DrawerTrigger, DrawerClose } from "@ux-sting/react/drawer";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add drawer
```

## Accessibility

- Dragging is optional: Escape, the overlay and close buttons also dismiss it.

| --- | --- | --- | --- |

| `closeThreshold` | `number` | `120` |  |
| `deferPointerDownOutside` | `boolean` | — | When `true`, a `'pointerdown'` event outside of the layered element will wait for the interaction's click event before dispatching, allowing third-party code to stop propagation of later events and cancel dismissal. |
