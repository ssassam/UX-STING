# Box

> Foundations · `@ux-sting/react/box`

The lowest-level layout primitive: a div (or any element via `as`) with `asChild` support.

## When to use

Use when you need a semantic wrapper element with styling and no layout opinion.

**Consider alternatives:** Prefer Stack, Grid or Container when you are arranging children.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Box } from "@ux-sting/react/box";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add box
```

## Accessibility

- Choose the semantic element with `as` (section, nav, article) instead of adding roles.

## API

### Box

The lowest-level layout primitive: a `div` (or any element) with `asChild`/`as`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `as` | `ElementType` | — |  |
| `asChild` | `boolean` | — | Render the child element instead, merging props (see `Slot`). |

_Also accepts 379 standard HTML/React attributes (className, style, aria-*, event handlers…)._
