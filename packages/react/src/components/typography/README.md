# Typography

> Typography · `@unified-ui/react/typography`

Text, Heading, Label, Caption, Code, Kbd, Link, Blockquote and Prose.

## When to use

Use for all text so sizes, colors and rhythm stay consistent with tokens.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Text, Heading, Label } from "@unified-ui/react/typography";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add typography
```

## Accessibility

- Heading separates semantic `level` from visual `size` — keep a sequential outline (h1 → h2 → h3).
- External links announce that they open in a new tab.
- Body text defaults to 16px on mobile with 1.5+ line height.
