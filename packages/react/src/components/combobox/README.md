# Combobox

> Forms · `@ux-sting/react/combobox`

Searchable single-select with groups, descriptions, async results and form submission.

## When to use

Use for long lists: countries, categories, users, cities.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Combobox } from "@ux-sting/react/combobox";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add combobox
```

## Accessibility

- Trigger exposes `role="combobox"`; results use `aria-activedescendant` so focus stays in the search field.

### Keyboard

| Keys | Action |
| --- | --- |
| ↑ / ↓ | Move through results |
| Enter | Select |
| Escape | Close |
