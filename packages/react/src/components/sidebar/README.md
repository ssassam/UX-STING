# Sidebar

> Navigation · `@unified-ui/react/sidebar`

Collapsible app sidebar (icon rail on desktop, sheet on mobile) with groups, items, badges and shortcut.

## When to use

Use for dashboards and apps with many sections.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { SidebarProvider, Sidebar, SidebarHeader } from "@unified-ui/react/sidebar";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add sidebar
```

## Accessibility

- Collapsed items keep their names for screen readers and show tooltips.
- SidebarTrigger exposes `aria-expanded`.

### Keyboard

| Keys | Action |
| --- | --- |
| ⌘B / Ctrl+B | Toggle the sidebar |

## Responsive behavior

Below `md` the sidebar becomes a slide-in sheet.

## API

### SidebarProvider

Application shell with a collapsible side navigation. On desktop the sidebar collapses to an icon rail; below `md` it becomes a slide-in sheet.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `collapsed` | `boolean` | — |  |
| `defaultCollapsed` | `boolean` | `false` |  |
| `onCollapsedChange` | `(collapsed: boolean) => void` | — |  |
| `shortcut` | `string \| false` | `"mod+b"` | Keyboard shortcut toggling the sidebar; `false` disables. |

_Also accepts 280 standard HTML/React attributes (className, style, aria-*, event handlers…)._
