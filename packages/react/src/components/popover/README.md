# Popover

> Overlays · `@ux-sting/react/popover`

Non-modal floating panel anchored to a trigger.

## When to use

Use for pickers, quick settings and small forms.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Popover, PopoverTrigger, PopoverAnchor } from "@ux-sting/react/popover";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add popover
```

## Accessibility

- Focus moves into the popover and returns to the trigger on close.

### Keyboard

| Keys | Action |
| --- | --- |
| Escape | Close |
