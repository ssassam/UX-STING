# Tag

> Data display · `@unified-ui/react/tag`

Categorization label (optionally removable) and selectable Chip.

## When to use

Use Tag for applied filters/keywords and Chip for quick filter toggles.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Tag, Chip } from "@unified-ui/react/tag";
```

Or copy the source into your project and own it:

```bash
npx unified-ui add tag
```

## Accessibility

- Remove buttons are labelled ("Remove Vegan"); Chip uses `aria-pressed`.
