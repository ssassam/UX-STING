# Slider

> Forms · `@ux-sting/react/slider`

Single value or range selection along a track (RangeSlider).

## When to use

Use for approximate values: price ranges, distance, volume.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { Slider, RangeSlider } from "@ux-sting/react/slider";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add slider
```

## Accessibility

- Each thumb has an accessible name (`thumbLabels`) and `aria-valuetext` from `formatValue`.

### Keyboard

| Keys | Action |
| --- | --- |
| ← → ↑ ↓ | Step (mirrored in RTL) |
| PageUp / PageDown | Large step |
| Home / End | Min / max |
