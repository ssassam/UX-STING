# Select

> Forms · `@ux-sting/react/select`

Custom single-select listbox with groups, typeahead and collision-aware positioning.

## When to use

Use for choosing one option from 5–15 options.

**Consider alternatives:** Use RadioGroup for fewer options, Combobox for long/searchable lists, NativeSelect on mobile-heavy forms.

## Installation

Use the package (tree-shakeable per-component entry point):

```tsx
import { SelectTrigger, Select, SelectGroup } from "@ux-sting/react/select";
```

Or copy the source into your project and own it:

```bash
npx ux-sting add select
```

## Accessibility
