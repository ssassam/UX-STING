# Maison Nord — e-commerce template

A home and lifestyle shop built with UX-STING: catalogue with filters, search, sorting and pagination, product pages with colour and quantity, a persistent cart drawer with a free-delivery progress bar, and checkout. Products are fictional; photos come from Wikimedia Commons (credited on `/credits`).

```bash
pnpm --filter @ux-sting/example-shop dev
```

- Brand theme: `app/providers.tsx` (ink on warm neutrals, serif display type).
- Cart state (saved in the browser): `app/providers.tsx`.
- Catalogue: `lib/data.ts`.
- Live demo: https://ssassam.github.io/UX-STING/shop/
